# AI Task Tracker v3 — Setup Guide

A powerful task management system with AI-powered planning and procrastination recovery.

**Features:**
- ✅ Full task & subtask management
- 🚀 AI Milestone Planner (generate day-wise plans from goals)
- ⏰ Procrastination Tracker (detect overdue tasks + offer AI recovery plans)
- 📅 Calendar week view
- 🔔 Web push notifications
- 🌙 Dark/light theme
- 📱 Responsive design

---

## Prerequisites

- **Python 3.10+**
- **PostgreSQL 13+** (or any modern version)
- **Node.js** (optional — only for frontend asset building)
- **Grok API Key** from [xAI Console](https://console.x.ai/) (free tier available)

---

## Installation

### 1. Clone / Extract the Project

```bash
unzip AI_TaskTracker_Procrastination.zip
cd AI_TaskTracker_modified
```

### 2. Set Up PostgreSQL

Create a new database for the app:

```bash
psql -U postgres
CREATE DATABASE ait_v3;
\q
```

Or using a GUI tool like pgAdmin.

### 3. Install Python Dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure Environment Variables

Copy `.env.example` to `.env` and fill in your values:

```bash
cp .env.example .env
```

**Essential variables to set:**

- `GROK_API_KEY` — Get this from [https://console.x.ai/](https://console.x.ai/)
  - Sign up (free account with free credits)
  - Go to your API console
  - Create an API key
  - Paste it in `.env`

- `DATABASE_URL` — Already defaults to PostgreSQL on localhost. If your setup differs, update it.

- `SECRET_KEY` — Keep the default for development, change in production

Example `.env` for local development:

```
APP_ENV=development
DEBUG=true
SECRET_KEY=dev-key-change-in-prod-32-chars-min!
DATABASE_URL=postgresql+asyncpg://postgres:root@localhost:5432/ait_v3
DATABASE_URL_SYNC=postgresql://postgres:root@localhost:5432/ait_v3
GROK_API_KEY=xai-xxx...
GROK_MODEL=gpt-oss:120b
GROK_API_BASE=https://api.x.ai/v1
```

### 5. Start the App

```bash
python main.py
```

You'll see output like:

```
═══════════════════════════════════════════════════
  AI Task Tracker  v3.0
  Running at  http://127.0.0.1:8000
  API Docs:   http://127.0.0.1:8000/api/docs
═══════════════════════════════════════════════════

✓ Database ready
✓ Admin created: admin@ait.com
✓ Scheduler started — reminders every 15 min, procrastination checks every 6 hours
```

### 6. Open in Browser

Visit **http://localhost:8000** and log in:

- **Email:** admin@ait.com
- **Password:** Admin@1234

## Usage Overview

### Dashboard
- Overview of all tasks: completed, in progress, overdue
- Recent tasks + due soon
- Navigation to other sections

### My Tasks
- Create, edit, delete tasks with priority, due date, tags
- Add subtasks to track progress
- Filter by status, priority, or tag

### AI Planner (🚀)
- **Input:** Goal title, description, deadline in days
- **Output:** Day-by-day actionable plan generated by Grok AI
- **Actions:** Review, edit, save as individual tasks

### Catch Up (⏰)
- **Procrastination detection:** Automatically flags overdue or stalled tasks
- **Actions per task:**
  - **📅 Reschedule** — Pick a new due date (optionally apply to all tasks with a tag)
  - **🤖 Break Down** — Generate an AI recovery plan that splits remaining work across days
  - **✅ Mark Done** — Quick completion
  - **🗑 Delete** — Remove the task

### Calendar
- Weekly view of all tasks by due date
- See task priority and progress
- Navigate weeks with prev/next/today

### Settings
- Profile: name, theme
- Change password
- Enable push notifications (requires VAPID keys)
- Delete account

## AI Features in Detail

### Milestone Planner

1. Go to **AI Planner** (🚀)
2. Enter:
   - **Goal Title** — e.g. "Learn React Basics"
   - **Description** — e.g. "Want to build interactive UIs with hooks"
   - **Deadline** — e.g. "14 days"
3. Click **✨ Generate Plan**
4. Grok AI generates a realistic 14-day breakdown
5. Review & edit day-by-day tasks
6. Click **💾 Save All Tasks** → creates 14 tasks (Day 1–14) in your task list

### Procrastination Tracker & Recovery

**How it detects procrastination:**
- Task is overdue (due_date < today)
- Task hasn't been updated in 3+ days
- Deadline was extended 2+ times

**When you see a task in Catch Up:**

1. **Reschedule only this task:**
   - Click **📅 Reschedule**
   - Pick new date
   - Save

2. **Reschedule all tasks with the same tag:**
   - Click **📅 Reschedule**
   - If task has tags, select "All [tag] tasks"
   - Pick new date
   - Saves new due date for all matching tasks

3. **AI Recovery Plan (Break Down):**
   - Click **🤖 Break Down**
   - Enter how many days to spread remaining work
   - Grok generates a plan that skips already-completed subtasks
   - Review & edit
   - Save → creates recovery tasks

**Example:**
- Original task: "Build Portfolio" due 10 days ago
- 3 of 10 subtasks done
- Click Break Down → enter "7 days"
- AI creates 7 new tasks for the remaining work
- Original task marked as in_progress with new due date

## Background Jobs

The app runs two scheduled tasks:

1. **Due Reminders** (every 15 min)
   - Finds tasks due within 24 hours
   - Sends push notification if subscribed

2. **Procrastination Alerts** (every 6 hours)
   - Finds overdue unnotified tasks
   - Sends one grouped notification per user
   - Example: "⏰ 3 tasks need your attention: Build Portfolio, Learn React, ..."

## Push Notifications (Optional)

To enable browser notifications:

1. Generate VAPID keys:
   ```bash
   python scripts/generate_vapid.py
   ```

2. Add to `.env`:
   ```
   VAPID_PRIVATE_KEY=...
   VAPID_PUBLIC_KEY=...
   ```

3. In Settings, click **🔔 Enable Notifications**
4. Grant browser permission
5. You'll now get reminders!

Works on: Chrome, Edge, Firefox (desktop + Android)  
Does NOT work on: iOS Safari (Apple restriction)

## API Documentation

Open **http://localhost:8000/api/docs** to see interactive Swagger docs for all endpoints.

### Key Endpoints

**Tasks:**
- `POST /api/v1/tasks` — Create task
- `GET /api/v1/tasks` — List tasks (with filters)
- `GET /api/v1/tasks/{id}` — Get task detail
- `PATCH /api/v1/tasks/{id}` — Update task
- `DELETE /api/v1/tasks/{id}` — Delete task
- `GET /api/v1/tasks/procrastinated` — Get overdue/staled tasks
- `POST /api/v1/tasks/{id}/reschedule` — Reschedule task or tag

**AI:**
- `POST /api/v1/ai/plan` — Generate milestone plan
- `POST /api/v1/ai/breakdown` — Generate recovery plan

## Troubleshooting

### "GROK_API_KEY is not set"

- Check your `.env` file has `GROK_API_KEY=xai-...`
- Make sure the value is not empty
- Restart the app after updating `.env`

### "Could not connect to PostgreSQL"

- Make sure PostgreSQL is running
- Check `DATABASE_URL` in `.env`
- Verify the database exists: `psql -U postgres -l`

### AI generation times out

- Grok API can take 30–60 seconds for complex plans
- Try with a simpler description
- Check your internet connection
- Verify your API key is valid

### "Unexpected plan format from AI"

- This means Grok returned invalid JSON
- Try rephrasing your goal description
- Use simpler language

### Push notifications not working

- Push only works on HTTPS in production (or localhost for testing)
- Browser needs to grant permission
- Check browser console for errors: `F12` → Console tab

## Production Deployment

For production:

1. Change `APP_ENV=production` and `DEBUG=false`
2. Generate a strong `SECRET_KEY` (32+ chars, random)
3. Set up PostgreSQL on a reliable host
4. Use HTTPS (get SSL cert from Let's Encrypt)
5. Consider using a reverse proxy (Nginx/Apache)
6. Run migrations if schema changes occur
7. Enable VAPID for push notifications

For HTTPS + Nginx example, see the main README.md.
